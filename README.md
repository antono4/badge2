# Badge2

> **Created by Antono** | 🇮🇩 Indonesia

A web-based badge and label maker application. Create beautiful badges for events, organizations, and more.

## ✨ Features

- 🎨 Design custom badges
- 📝 Add text and graphics
- 📥 Download in various formats
- 📱 Mobile-friendly

## 🚀 Getting Started

```bash
git clone https://github.com/antono4/badge2.git
cd badge2
open index.html
```

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
